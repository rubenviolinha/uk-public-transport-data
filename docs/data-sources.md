# Data sources and attribution

## Bus Open Data Service (BODS)

The bus pilot uses the UK Department for Transport's Bus Open Data Service for
scheduled data and live vehicle information. Before publishing a consumer
product or redistributing data, check the provider's current licence,
attribution, and service terms.

## National Rail Darwin

The railway pilot uses the National Rail Darwin Push Port snapshot and live
topic feeds. Darwin data is used to derive a normalised Rugby departure board;
upstream credentials and raw snapshots are not committed to this repository.

Before release, confirm the current Darwin terms, any required attribution, and
whether the intended display or API use is permitted.

## Project rule

Every new transport source must be documented with its owner, permitted use,
required attribution, update frequency, and the project components that consume
it.
